# .github

Fichiers communs à l'organisation Automatic Dashboard :

- `profile/README.md` : la présentation affichée sur la page de l'organisation ;
- `SECURITY.md` : comment nous signaler une faille, valable pour tous nos dépôts ;
- `CODE_OF_CONDUCT.md` : le code de conduite, dans les tickets, les discussions et les pull requests ;
- `FUNDING.yml` : le bouton « Sponsor » des dépôts.
