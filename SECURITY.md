# Signaler une faille de sécurité

Automatic Dashboard tourne dans votre Home Assistant, avec les droits de la personne connectée. L'intégration ne crée aucune entité, n'ouvre aucun accès et n'envoie aucune donnée hors de Home Assistant ; le tableau lit seulement ce que l'interface de Home Assistant lui fournit. Si vous trouvez une faille dans l'un de nos dépôts ou sur le site, merci de nous la signaler en privé.

## Comment faire

1. Ouvrez l'onglet **Security** du dépôt concerné.
2. Cliquez sur **Report a vulnerability** (signalement privé).
3. Décrivez ce que vous avez trouvé, comment le reproduire et ce qu'un attaquant pourrait en faire.

N'ouvrez pas de ticket public pour une faille : elle serait visible de tous avant d'être corrigée.

## Ce que nous faisons ensuite

Vous avez une réponse sous une semaine. Nous vérifions le problème, puis nous publions le correctif dans une nouvelle version, avec votre nom si vous le souhaitez.

Seule la dernière version reçoit des correctifs : mettez Automatic Dashboard à jour depuis *Paramètres*, *Mises à jour*.

---

*In English: never report a vulnerability in a public issue. Use GitHub's private reporting (Security tab, "Report a vulnerability") on the repository concerned. You will get an answer within a week. Only the latest version receives fixes.*
